# ВосьмиБитва

Русскоязычный сайт турнира NES/Famicom от FoxyShadow. Готовый статический сайт для GitHub Pages: HTML, CSS, JavaScript, локальные шрифты и SVG-иллюстрации. Сборка, база данных, API-ключи и установка зависимостей не нужны.

## Публикация

1. Добавьте новые файлы этого каталога в Git, создайте коммит и отправьте его в GitHub.
2. В репозитории откройте **Settings → Pages → Build and deployment**.
3. Выберите **Deploy from a branch**, ветку **master**, каталог **/ (root)** и сохраните настройки. Если используете другую ветку, выберите её.
4. Дождитесь успешной публикации. Последующие коммиты в выбранную ветку будут публиковаться автоматически.

Файл `.nojekyll` отключает обработку Jekyll. Существующий `CNAME` с доменом `8bit.decavoid.com` сохранён. Настройки DNS и HTTPS управляются отдельно в GitHub Pages. Это также работает по стандартному адресу проекта `https://decavoid.github.io/fox-8-bit/`: все внутренние ссылки относительные.

Основание для настройки: [документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Обновление турнира

Редактируйте файлы в `data/`, сохраняйте в UTF-8 и отправляйте изменения в GitHub. Открытая страница проверяет обновления раз в минуту и при возвращении на вкладку. Поиск, выбранный этап и раскрытые правила сохраняются при обновлении.

| Файл | Содержимое |
| --- | --- |
| `data/scores.txt` | Этапы, матчи, счёт и официальные призовые места |
| `data/players.txt` | Один ник участника на строку |
| `data/rules.md` | Полный текст правил в Markdown, даты и призы |

### Матчи

Заголовки `##` задают этапы. Строка матча имеет четыре поля: `Игрок 1 | Счёт | Игрок 2 | Счёт`. Заголовок таблицы `Player 1 | Score | Player 2 | Score` можно оставить. Пустые строки важны.

```text
## Раунд 1
Player 1 | Score | Player 2 | Score

Deeper | 1 | neradimo | 2

Serxio |   | Billy |

dilat    | 1 | Mr(A)ked    | 0
dilat    | 1 | arcade_user | 0
Mr(A)ked | 0 | arcade_user | 1
```

- Отдельные матчи разделяются пустой строкой.
- Три соседние строки без пустых строк образуют группу, если в них ровно три разных участника и каждая пара встречается один раз. Такая группа всегда отображается целиком, в том числе при поиске и фильтрации.
- Пустой счёт, `—`, `-` или `?` означает, что результат ещё не указан. Ноль — настоящий счёт, а не отсутствие данных.
- Два разных числовых результата означают завершённый матч: выигрывает участник с большим счётом. В этом формате нет отдельного признака текущей игры; записывайте окончательный результат после матча.
- При равном счёте победитель не назначается. Такие матчи входят в фильтр «Предстоящие» вместе с матчами без результата.
- Два победителя группы определяются по количеству выигранных матчей после завершения всех трёх встреч. Если у всех по одной победе, сайт сообщает о переигровке; разница очков не используется как дополнительный критерий. После переигровки замените три строки группы новыми результатами.
- Пустые этапы показываются с сообщением, что соперники ещё не определены.
- Ошибки формата отображаются над сеткой. Соседние строки, не составляющие корректную тройку, показываются отдельными матчами с предупреждением.

Призовые места задаются явно, отдельно от результатов матчей:

```text
## Победители
Place | Player

1 | dilat
2 | neradimo
3 | Serxio
```

До объявления победителей оставьте имена пустыми. Сайт не назначает чемпиона автоматически. Файл `data/scores.example.txt` остаётся локальным примером и не используется сайтом; для автоматических проверок его содержимое сохранено в `tests/fixtures/scores-upcoming.txt`.

### Правила, даты и призы

Каждый раздел `##` в `rules.md` становится раскрывающимся блоком. Поддерживаются заголовки, абзацы, жирный и курсивный текст, списки, цитаты, встроенный код, ссылки и переносы строк через два пробела. HTML выводится текстом.

Дата и призовые суммы на главной странице извлекаются из текста правил. Чтобы они обновлялись автоматически, сохраните текущую форму предложений, например:

```text
Турнир будет проходить 6, 7 и 8 ноября (если участников будет немного, то 7 и 8 ноября).
Призовой фонд турнира составит 25000 рублей.
Первое место получает 18000 рублей, второе 6000 рублей, третье 1000 рублей.
```

Если дата или сумма написана в другом формате, сайт покажет нейтральную подпись со ссылкой на правила. Сам текст правил отображается целиком. Год и время начала не выдумываются; для них в исходных данных нет значений.

Ссылки на Twitch и YouTube находятся в `index.html`. Они ведут на каналы FoxyShadow и не предполагают, что трансляция уже идёт. Название и вступительный текст также редактируются в `index.html`.

## Локальный просмотр

Требуется Node.js 22 или новее. Из этого каталога:

```sh
npm start
```

Откройте `http://127.0.0.1:4173/`. Для проверки размещения в подпапке доступен `http://127.0.0.1:4173/fox-8-bit/`. Остановка — `Ctrl+C`. Сервер слушает только локальный интерфейс. Простое открытие `index.html` через `file://` не подходит: браузер блокирует чтение файлов данных через `fetch`.

## Проверки

```sh
npm test
```

Тесты проверяют завершённые и будущие матчи, пустые и нулевые значения, группировку, тройную ничью, поиск и фильтры, призовые места, Markdown и защиту от HTML-вставок. Стабильные примеры находятся в `tests/fixtures/`, поэтому изменение числа игроков и результатов турнира не требует переписывать тесты. Дополнительно проверяется формат текущего `scores.txt`.

## Файлы сайта

- `index.html` — структура, основной текст, навигация и ссылки на трансляции.
- `assets/styles.css` — оформление и адаптивные раскладки.
- `assets/app.js` — загрузка и обновление данных, отображение, поиск и фильтры.
- `assets/tournament.js` — независимые функции чтения данных и подсчёта результатов.
- `assets/controller.svg`, `assets/favicon.svg` — оригинальные векторные иллюстрации.
- `assets/fonts/` — Golos Text и Russo One; лицензии SIL Open Font License включены.

Шрифты и иллюстрации загружаются с самого сайта. Внешние скрипты, аналитика, cookies и сторонние запросы при открытии страницы не используются.
